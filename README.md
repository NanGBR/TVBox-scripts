# Testes de Desempenho de CPU e GPU

Este repositório foi criado como parte do meu Trabalho de Conclusão de Curso (TCC), com o objetivo de realizar testes e analisar o desempenho computacional de dispositivos de hardware limitado, permitindo comparar seu comportamento sob diferentes cargas de processamento.

O repositório contém dois scripts para realização de testes de desempenho:

- **CPU:** Realiza testes de estresse e desempenho do processador, analisando seu comportamento durante cargas intensivas de processamento.
- **GPU:** Realiza testes de desempenho da unidade gráfica, permitindo avaliar sua capacidade de processamento e comportamento sob carga.

Os scripts auxiliam na coleta de dados e na análise do desempenho do hardware, servindo como base para os experimentos e resultados apresentados no TCC.
